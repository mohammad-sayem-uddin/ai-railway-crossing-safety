# HISTORICAL — OLD TEST DATASET — RETIRED

**Archived Date:** 2026-10-07  
**Status:** RETIRED / REPLACED  

This directory preserves the historical metadata, labels, and manifests for the initial 21-event Layer B dual-camera train-passage evaluation dataset.

The raw evaluation video media (`1.mov` to `21.mov`, front and back) and extracted audio files were intentionally retired and removed on 2026-10-07 to make room for a new, cleaner, and larger evaluation dataset.

Historical benchmark results (B0–B7) in `results/experiments/` are preserved for research traceability and reproducibility.
