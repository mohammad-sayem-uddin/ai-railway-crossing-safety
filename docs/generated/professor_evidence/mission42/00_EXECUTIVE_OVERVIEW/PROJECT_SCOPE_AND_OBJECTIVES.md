# Project scope and objectives

Assess the existing B0_front, B0_back, B1_audio and B2_front stages under the adopted five-event pilot and existing M4/M5/MTR framework. Independent cameras are primary, fusion exploratory and audio supporting only. This package introduces no new novelty claim, scientific threshold, inferential test or experiment.

The pilot contains train_events/event_005, train_events/event_021, engine_events/event_001, train_events/event_001 and no_train_events/event_001, front/back each. It is a selected pilot within the 27-candidate cohort (23 train, three no-train, one engine; 54 camera references), retaining two duplicate exclusions. Metric eligibility, censoring, uncertainty and denominators are assessed per metric rather than assigning N=5 universally.

Optional R04 remains exactly eleven pairs with event_010 excluded. Physical T2/occupancy, RD046 sufficiency and the inactive comparator remain deferred. No training, calibration, new split/CV, new site/sensor, hardware actuation, manuscript or professor contact is included in Mission42.

Mission42 now authorizes this professor evidence preparation despite earlier package pauses. It does not retroactively approve GT, sign a human record, issue a replay grant or authorize public raw-media release.
