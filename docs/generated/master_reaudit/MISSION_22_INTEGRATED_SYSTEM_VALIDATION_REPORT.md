## Defects found and fixed

- Review and authority services owned separate transactions. A versioned shared transaction now binds current permission, immutable review operation, both journals and quota; the anchor advances after commit.
- Persisted review context was only checked at opening. Use/recovery now validates context/schema and the exact retained prefix. ACK step cannot skip its journal anchor.
- A malformed stored receipt escaped as an uncontrolled construction error. It now refuses with a controlled diagnostic.
- SQLite could automatically roll back on capacity failure; unconditional ROLLBACK masked SQLITE_FULL. Both transaction owners now preserve the original error and note a secondary rollback failure.
- Camera/physical-event/display aliases and lineage/artifact identities lacked explicit cross-package joins. Exact constructed identity, camera and transitive-exposure joins now refuse substitutions or missing streams.
- Fresh tuple-rich results differed from resumed JSON. Public results now use the same canonical JSON values.
- Completion could omit artifacts or accept coherently rehashed changed B output. Closed artifact names plus full deterministic B/metric/lineage replay checks now refuse those substitutions.
- Resumed RUN/DB/snapshot metadata aliases could be opened before validation. Parent-first named-path checks now reject aliases before read/connect. Hostile concurrent path replacement remains outside this cooperative profile.
- The boundary projection imported the inactive proposed schema despite its import fence. It now emits a limited non-promotable wire projection without activating that module.
- The metadata-opener inventory and test-access manifest were stale. New bounded metadata hash sites are reviewed explicitly; new/changed test classifications conservatively remain UNKNOWN pending the original classifier. No invented classifier pass counts or safe flags were added; the Mission22 runner still executes every module.

Development also exposed runner-only defects: temporary-root mismatch, missing child-tool inheritance, loopback handling, temporary-registry fixture return shape and FD-relative cleanup resolved against cwd. These were corrected without changing product validators. The final policy child test verifies prohibited reads/writes/network/child calls are denied while loopback and temporary cleanup succeed. Four apparent legacy staging-cleanup failures disappeared after the FD-relative policy fix; the evaluation runner itself was not changed.
