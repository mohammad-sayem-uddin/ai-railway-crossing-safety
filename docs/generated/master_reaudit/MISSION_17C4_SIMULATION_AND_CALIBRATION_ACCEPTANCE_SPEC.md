## 1. Synthetic causal runner contract

SC01. Mission17D implements SYNTHETIC_CONVENTION_B_V1 in a new isolated standard-library package. It accepts only explicitly constructed synthetic event objects/in-memory commands, never media/features, file paths, a real-data loader or a research controller. Historical runner/gate/controller/config/Table11 bytes remain unchanged. Commanded actuator fixtures are distinct from integrated controller parity. A future actual-controller adapter must separately prove its input/output/time contract before use; this phase makes no such integration or research-policy change.

SC02. Timestamp input is an integer number of microseconds (bool rejected), or a finite nonnegative decimal-seconds string exactly on the microsecond grid. No binary float is accepted implicitly. An explicitly named legacy_float_to_us adapter parses repr(value) as its shortest round-trip decimal, verifies a finite nonnegative float and exact grid membership, then converts without rounding. Thus0.2 maps to200000;0.1+0.2 is off-grid and rejects. This is a documented legacy representation policy, not a claim that binary0.2 equals1/5 or any scientific accuracy. Angles/rates are exact integers/decimal strings/rational arithmetic; floats, NaN and infinity reject. Strict internal b(theta)=theta≤45 never uses display rounding/epsilon. Numeric equality at45 is blocked.

SC03. P3 default initial90°, close/open3s, rate30°/s, clipped[0,90]. CLOSED/CLOSING map LOWER, OPEN/OPENING map RAISE, HOLD explicitly preserves angle. A provided nested command must normalize to the same command as its target; conflict aborts before activation, missing nested intention is marked DERIVED_FROM_TARGET. The initial accepted event at t0 has no preceding actuation; it issues u0 only for t>t0. Later accepted events propagate the prior active command over (last,current] before issuing current command. Interval records bind start/end/dt, pre/post angles, actual applied command, origin/effective time, event kind and endpoint blocked bit; command issue records remain separate.

SC04. ARRIVAL preserves input order and rejects duplicate/older canonical timestamps without changing accepted clock, command, physical angle, observation counts or duration. Rejections record input index/time/reason separately. OFFLINE validates the entire input before stable sorting(time,input index); duplicate handling remains explicit and its reordering flag disclaims arrival-fault evidence. Invalid encountered timestamp/command returns an INCOMPLETE result containing a clearly labeled accepted prefix and reason, never fabricated time or completed totals. OFFLINE invalid input yields no accepted prefix because it validates before sorting. Invalid configuration/type/initial state is rejected before run initialization.

SC05. Default horizon is last accepted observation; no implicit media duration or hidden pre-origin interval. Explicit cutoff before origin rejects; at origin gives zero duration; inside a later interval integrates only to cutoff without evaluating/activating the later event; beyond last observation propagates the still-active command/timers and records CUTOFF without a fabricated sensor. Empty input yields EMPTY, no angles/origin/horizon and zero durations; a single accepted event has no duration unless explicit cutoff extends it. A malformed event encountered before an established cutoff aborts; processing stops once cutoff has been reached.

## 2. Explicit optional watchdog engineering profiles

SC10. Default is NONE. Optional SCHEDULED uses an explicitly supplied positive integer timeout_us and response command. Each accepted valid sensor schedules a single generation at last_seen+timeout. At exact sensor/timer collision SENSOR_FIRST wins: valid sensor cancels/reschedules that generation before firing; duplicate/older rejected arrivals do not reset it. Within a gap, integrate old command to the timer, log TIMER, issue response only after timer, then integrate onward. No recurrence occurs until a new accepted sensor resets the generation. Timer events never fabricate observations. A cutoff equal to due time may record the event but adds no post-cutoff motion.

SC11. Optional DETECT_ON_ARRIVAL integrates the old command through the gap. If current accepted sensor gap>timeout (equality is sensor-first non-timeout), log gap detection at current boundary; the configured response overrides the sensor's requested command at that boundary and affects only future intervals. The requested intention remains logged separately. With no later valid sensor there is no independent timeout. Both profiles are explicitly named synthetic alternatives; timeout/response/priority/recurrence choices here are engineering test parameters, not adoption of a research or railway fail-safe policy. Controller source-staleness/warning behavior remains unchanged. W1/W2 fixture sensors1,1.2,4.2, timeout2s, priorH,responseL yields60°/90° respectively at4.2; both durations0.

## 3. Operation-specific fitting and leakage boundaries

SC12. BASE_MODEL_FIT changes model parameters; PREPROCESSOR_FIT learns input transform/statistics/features; CALIBRATOR_FIT fits the prospectively declared score/threshold calibration rule; SELECT uses outcomes to choose architecture/checkpoint/threshold/early stopping. A FEATURE_CACHE inherits every producing artifact's FIT/SELECT memberships. Merely allocating a metadata role does none of these operations. Human inter-rater calibration/pilot(X07) is separate from model/score calibration and grants no FIT operation.

SC13. For an outer iteration, BASE_MODEL_FIT and PREPROCESSOR_FIT use INNER_TRAIN, or an explicit prospectively frozen final-refit rule on OUTER_TRAIN_POOL. SELECT may use INNER_TUNE and permitted training history, never OUTER_EVAL. CALIBRATION_ONLY means excluded from base-model/preprocessor fitting and independent evaluation, but permitted for CALIBRATOR_FIT under an explicit RESERVED_CALIBRATION rule. This resolves the unqualified “excluded from fitting” ambiguity; it does not move any existing V2 case into calibration.

SC14. INNER_OOF calibration uses only scores produced for INNER_TUNE cases by inner models whose fit/selection provenance excludes the scored event; all data stay within the outer training complement. RESERVED_CALIBRATION uses only prospective CALIBRATION_ONLY events, outside outer evaluation/base/preprocessor fit/selection roles. NONE fits no calibration transform. Final outer refit/calibrator composition must be prospectively specified and expose all contributing data memberships; formerly selected/calibrated cases cannot be called unseen.17D validates role/fit-membership metadata only; it implements no model/preprocessor/calibrator fitting, no prediction OOF generation and no scientific tolerance estimator.

SC15. RESERVED_CONTROL cannot enter FIT/SELECT/CALIBRATOR_FIT while retaining independent control status. CASE_STUDY remains separately reported; RD024 is pooled-outcome exclusion, not a new training ban/zero-shot approval. RD025 no-train status still needs human confirmation and event/exposure reporting, not FAR/hour. FINAL_DESCRIPTIVE never becomes a development pool because a split helper exists. Unknown initialization/training exposure prohibits independent held-out/generalization claims. All real corpus/scientific eligibility/adoption decisions remain R03/R06 pending.
