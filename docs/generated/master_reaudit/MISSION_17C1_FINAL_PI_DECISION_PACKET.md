## 1. Separate three approval categories

1. Researcher decisions set scientific authority, camera/corpus roles, metrics and human governance. A recorded existing RD direction remains the design baseline unless explicitly amended; C1 does not demand reapproval merely to state it accurately.
2. Technical decisions select a testable architecture/contract within the approved scientific scope. The researcher's acceptance of risk/scope is distinct from a maintainer's technical recommendation. Some choices can be developed with synthetic fixtures before final protocol promotion or real human-review receipts.
3. Execution authorization permits a particular bounded action/resource set. Neither a technical recommendation nor a scientific approval issues this authority. Current mission authorization covers only safe forensic work and the four-document commit/push workflow; it ends at this packet.

C0's six-step gate order already makes these distinctions in prose and correctly avoids requiring a review's own future promotion receipt before review. The revision here separates its mixed D table into explicit categories and narrows overstated evidence. It does not claim C0 authorized protected execution.
