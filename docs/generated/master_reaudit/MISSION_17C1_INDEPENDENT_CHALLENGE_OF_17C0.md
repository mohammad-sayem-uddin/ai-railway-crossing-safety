## 5. Mathematical challenge and historical evidence

The existing runner evaluates at t_k and applies resulting_gate_state over dt_k before accumulating blocked time: `src/railway_detection/simulation/runner.py:185-233`; actuator motion/thresholds: `src/railway_detection/simulation/gate_model.py:19-71`. Convention B instead propagates the preceding active command across (t_(k−1),t_k], then observes/evaluates at t_k and issues a future command. A controller whose future command depends on the newly propagated state can generate a different sequence from the historical runner. The following theorem therefore compares **externally fixed common commands**, not arbitrary re-executed closed-loop controllers.

Let F be the same deterministic actuator transition in both conventions. For a uniform h and common initial theta0:

    A_k = F(A_(k−1), u_k, h)
    B_k = F(B_(k−1), u_(k−1), h)

If F(theta0,u0,h)=theta0, B1=A0. Inductively B_k=A_(k−1). With the same blocked predicate b and the same endpoint-weighted horizon k=1…N:

    T_B − T_A = h * sum(b(A_(k−1)) − b(A_k))
              = h * (b(A0) − b(A_N)).

For an initially open gate this is−h when the A endpoint is blocked,0 otherwise. One episode is unnecessary; equal raising/lowering rates are unnecessary if both conventions use the same rates. The initial fixed-point condition, common commands/dynamics/classifier/horizon are essential to this proof. Initial LOWER violates the fixed-point assumption at 90°. An initially blocked state gives a different boundary term. For irregular intervals only sum(dt_k*(b(B_k)−b(A_k))) is generally valid; a partial terminal interval supplies no universal−dt_final shortcut.

This endpoint sum is not the continuous threshold integral. For example, initial90°, LOWER at t0, speed 30°/s, h=.2 and horizon2s: physical blocked duration is.5s after the 1.5s crossing; the endpoint B sum is.6s. Forward causality does not remove quadrature error.
